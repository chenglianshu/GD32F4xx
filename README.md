GD32F4xx grblHAL Driver
grblHAL driver for GD32F405xx, GD32F407xx, and GD32F425xx ARM processors.

This will be the world's first project to port grblHAL to GigaDevice's GD32F4xx series chips; the primary reason for undertaking this port is that I happen to have a few CNC control boards based on the GigaDevice GD32F425RET6 on hand.

This project has been tested on actual hardware; limit switches, homing, spindle movement for engraving, the laser, and SD card functionality all operate correctly.
